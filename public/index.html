1 · Color strength

Which colors have the most power and depth?

Ranked by depth (copies above set-avg GIH), then power (top 3 by GIH). Mixed-set pools compare each card to its own set average. Top colors are shown first.

2 · Best pairs

Which color pairs make sense from that?

Pair lanes still include both monocolors plus the gold pair. Default list is the best few, not all ten. Depth still uses each card's own set-average GIH.

3 · Fixing & splash

How does fixing support strong cards not in the main pair?

Mana evaluation from Scryfall oracle text, not GIH. Colored duals still count in their color and pair lanes.
